Welcome to Recursive Robotic Swarms

An interactive documentation on autonomous robotic swarms for voxel-based construction.

Project Overview


This documentation is based on prior work conducted by Amira Abdel-Rahman. It presents a comprehensive guide on how to set up, understand, and modify the Recursive Robotic Swarm simulation using Three.js.

The project focuses on swarm-based voxel construction, where one or multiple autonomous robots collaborate to build structures efficiently.

This work is part of a broader research project on voxelized structure conducted at the Center of Bits and Atoms ( CBA ) at the MIT Media Lab. To access some of the previous done about this subject click on the Bibliography Bellow:
