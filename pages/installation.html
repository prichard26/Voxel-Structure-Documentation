Installation Guide

Follow these steps to set up your environment and start creating or modifying the Recursive Robotic Swarm simulation.

  • 1. Install VS Code and Live Server Extension

    Download and install Visual Studio Code. Then, open VS Code and install the Live Server extension from the marketplace.

  • 2. Open Your Project Folder

    Launch VS Code and open the folder containing your project files.

  • 3. Locate and Open index.html

    In VS Code, find index.html in your project directory and open it.

  • 4. Start Live Server

    Click the 'Port: XXXX' button in the bottom-right corner of VS Code, then select 'Go Live'.

A new browser window should open, displaying the simulation. Any changes you make to the code will update automatically—no need to refresh manually!
