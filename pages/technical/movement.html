🦿 Robot Movement Set

How the Bill-E robot executes different movements to navigate the voxel world.

📖 Understanding the Movement System

The Bill-E robot moves using a **set of predefined movements**, allowing it to walk, turn, climb, and reposition in a voxel-based environment. Each movement is performed by **updating joint angles** and **swapping the fixed leg**.

✔ How Movements Work:

  • ✅ The robot has a fixed leg and a moving leg.
  • ✅ It can move forward, turn, climb up/down, and swap legs.
  • ✅ Movements are **executed sequentially**, ensuring stability.
  • ✅ The movement strategy is **adapted to terrain constraints**.

🚀 Movement Types

Below are the main movement actions available:

🦿 Go Forward

Moves the robot **one step forward** while keeping the same orientation.

↪️ Turn Right / Turn Left

Rotates the robot **90 degrees** to the left or right.

⏫ Climb Up

Moves forward and **steps up onto a higher surface** if space allows.

⏬ Climb Down

Moves forward and **steps down onto a lower surface** if it exists.

🔄 Switch Leg

Swaps the **fixed leg**, allowing movement in the opposite direction.

⚙️ The `executeMovement()` Function

The function executeMovement() handles movement execution by **updating angles and swapping legs** if necessary.

executeMovement(action)

📥 Inputs:

  • action: The movement type (e.g., "goForward", "turnRight").

📤 Output:

  • Applies the movement by **updating joint angles** and **positioning the robot correctly**.
    function executeMovement(action) {
        switch (action) {
            case "goForward":
                robot.target.position.add(robot.forward.clone().multiplyScalar(STEP_SIZE));
                break;
            case "turnRight":
                robot.direction.applyAxisAngle(robot.normal, -Math.PI / 2);
                break;
            case "turnLeft":
                robot.direction.applyAxisAngle(robot.normal, Math.PI / 2);
                break;
            case "climbUp":
                robot.target.position.add(robot.forward.clone().multiplyScalar(STEP_SIZE))
                                     .add(robot.normal.clone().multiplyScalar(STEP_SIZE));
                break;
            case "climbDown":
                robot.target.position.add(robot.forward.clone().multiplyScalar(STEP_SIZE))
                                     .sub(robot.normal.clone().multiplyScalar(STEP_SIZE));
                break;
            case "switchLeg":
                robot.swapFixedLeg();
                break;
        }
        robot.updateAnglesFromTarget();
    }

🎯 Example Usage

Execute a movement using the robot’s movement system:

    import { executeMovement } from "./movement.js";
    
    // ✅ Move the robot forward
    executeMovement("goForward");
    
    // ✅ Turn right
    executeMovement("turnRight");
    
    // ✅ Climb up a step
    executeMovement("climbUp");
    
    // ✅ Swap legs to move in another direction
    executeMovement("switchLeg");

Each movement updates the robot’s **position and angles**, ensuring correct motion.
