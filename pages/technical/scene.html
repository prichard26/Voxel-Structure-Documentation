🌎 Scene in Bill-E Simulation

How the Three.js scene is set up and structured.

📖 Theoretical Background

In Three.js the scene serves as the 3D world where objects are placed. It includes:

  • 💡 Lighting: – Used to control how objects appear.
  • 🎨 Background & Color – Defines the scene's ambiance.
  • 🛠 Grid & Helpers – Provides a reference system for navigation.
  • 🎥 Camera & Controls – Allows rotating, zooming, and panning within the scene.

⚙️ Usable Function

One core function is used to set up the scene:

initScene()

📥 Inputs: None

📤 Output: A fully initialized Three.js scene.

function initScene() {
    const scene = new THREE.Scene();
    scene.background = new THREE.Color(0x87ceeb); // Light blue sky color
    
    const gridHelper = new THREE.GridHelper(20, 20);
    scene.add(gridHelper);
    
    const ambientLight = new THREE.AmbientLight(0xffffff, 0.6);
    scene.add(ambientLight);
    
    return scene;
}

🎯 Example Usage

Initialize the scene and add elements:

import * as THREE from "three";
import { initScene } from "./scene.js";

const scene = initScene();
const geometry = new THREE.BoxGeometry();
const material = new THREE.MeshStandardMaterial({ color: 0xff0000 });
const cube = new THREE.Mesh(geometry, material);

scene.add(cube); // ✅ Adding objects to the scene
