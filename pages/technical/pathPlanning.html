🗺️ Path Planning

How Bill-E navigates through voxel environments using A* search.

📖 Understanding Path Planning

The Bill-E robot navigates a **voxel-based environment** using an adapted **A* search algorithm**. The goal is to compute an optimal sequence of movements to reach a target while avoiding obstacles.

✔ How Path Planning Works:

  • 🗺️ The environment is represented as a **3D grid of voxels**.
  • 🚀 A* search explores possible moves and selects the **most efficient path**.
  • ✅ The robot can **walk, turn, climb, and swap legs** to navigate different terrains.
  • ⚠️ The algorithm must **handle deadlocks and prevent getting stuck**.

🚀 Key Features

  • ✅ A* Search Algorithm: Finds the shortest path while considering movement constraints.
  • ✅ Dynamic Obstacle Avoidance: Ensures no movement passes through solid voxels.
  • ✅ Multi-Terrain Navigation: Includes actions for climbing, turning, and swapping legs.
  • ✅ Prevents Deadlocks: Avoids getting stuck by adjusting heuristics.

⚙️ The `planPathToCoordinate()` Function

The function planPathToCoordinate() computes an **optimal movement path** from the robot's current position to a target voxel.

planPathToCoordinate(goalLegPosition, goalNormal)

📥 Inputs:

  • goalLegPosition: The target voxel where the robot should move.
  • goalNormal: The normal vector at the target, ensuring the robot is correctly oriented.

📤 Output:

  • A computed **sequence of movements** for the robot to follow.
async function planPathToCoordinate(goalLegPosition, goalNormal) {
    const STEP_SIZE = 1.0;
    const MAX_ITERATIONS = 50000;
    
    if (!voxelExists(goalLegPosition, goalNormal)) {
        console.warn("❌ Target voxel doesn't exist:", goalLegPosition);
        return { success: false, path: [] };
    }

    let openSet = [{ position: this.target.position.clone(), normal: this.target.normal.clone(), path: [] }];
    let visited = new Set();

    while (openSet.length > 0) {
        openSet.sort((a, b) => heuristic(a.position) - heuristic(b.position));
        let current = openSet.shift();
        if (!current) continue;

        let currentKey = serialize(current.position, current.normal);
        if (visited.has(currentKey)) continue;
        visited.add(currentKey);

        if (current.position.distanceTo(goalLegPosition) < 0.01 && current.normal.angleTo(goalNormal) < 0.1) {
            return { success: true, path: current.path };
        }

        for (let move of possibleActions) {
            if (move.condition && !move.condition()) continue;
            let neighborPos = current.position.clone().add(move.moveVec);
            if (!voxelExists(neighborPos, move.newNorm)) continue;
            let newPath = [...current.path, { position: neighborPos, action: move.action }];
            openSet.push({ position: neighborPos, normal: move.newNorm, path: newPath });
        }
    }

    console.warn("❌ No valid path found.");
    return { success: false, path: [] };
}

🎯 Example Usage

Compute a path and execute the robot’s movements:

import { planPathToCoordinate } from "./path_planner.js";

const goalPos = new THREE.Vector3(5, 2, 0);
const goalNormal = new THREE.Vector3(0, 0, 1);

const { success, path } = await planPathToCoordinate(goalPos, goalNormal);

if (success) {
    path.forEach(step => {
        robot.executeMovement(step.action);
    });
}

If a valid path is found, the robot will follow the computed movement sequence.
