📐 Inverse Kinematics (IK)

How the robot computes the joint angles needed to reach a target position.

📖 Understanding Inverse Kinematics

Inverse kinematics (IK) is used to compute the joint angles required to move the robot's foot to a specific target. Since Bill-E is a 5-DOF bipedal system but can be represented as a 4 DOF arm, solving IK is done in two main steps:

  • ✔ Step 1: Compute Joint 0 (\(\theta_0\)) - Yaw Rotation (rotation around the Z-axis).
  • ✔ Step 2: Compute Joints 1, 2, 3 (\(\theta_1, \theta_2, \theta_3\)) - Positioning the moving leg.

Step 1: Computing Joint 0 (Yaw Rotation)

The first step is computing \(\theta_0\), which aligns the leg toward the target in the plane of the 2 legs.

📌 How It Works:

  • Project the target position onto the leg's plane.
  • Compute the angle between the robot’s current direction and the projected target.

\[ \theta_0 = \text{atan2} \left( (\mathbf{direction} \times \mathbf{target}_{\text{proj}}) \cdot \mathbf{normal}, \mathbf{direction} \cdot \mathbf{target}_{\text{proj}} \right) \]

(1)

Step 2: Solving 3-DOF Inverse Kinematics

Once \(\theta_0\) is known, we solve for \(\theta_1, \theta_2, \theta_3\), which define the bending of the leg. As we want the leg to reach a position with a specific orientation we always have a constraint on theta3.

📌 How It Works:

  • Compute the distance \( d \) from the base to the target.
  • Use trigonometry and the law of cosines to compute joint angles.

\[ \cos(\theta_2) = \frac{x^2 + y^2 - L_1^2 - L_2^2}{2 L_1 L_2} \]

(2)

\[ \theta_1 = \tan^{-1} \left( \frac{y}{x} \right) - \tan^{-1} \left( \frac{L_2 \sin(\theta_2)}{L_1 + L_2 \cos(\theta_2)} \right) \]

(3)

\[ \theta_3 = \psi - (\theta_1 + \theta_2) \]

(4)

⚙️ Method: updateAnglesFromTarget()

This method in the THREERobot class computes the necessary angles so that the robot correctly positions one leg at origin and the other at target.

To use this method properly, you must first set your target position and orientation. Once defined, calling updateAnglesFromTarget() will automatically update the robot’s joint angles to match the desired configuration.

The function follows these key steps:

  • ✔️ Compute the direction between the origin (fixed leg) and target (moving leg).
  • ✔️ Project the target onto the plane of the fixed leg to determine rotation.
  • ✔️ Solve Inverse Kinematics (IK) for the 3-joint leg mechanism.
  • ✔️ Apply the computed angles to the robot’s joints.

🎯 Example Usage: Updating Robot Angles

Below is an example of how to initialize the robot, set a new target position, and update the angles using updateAnglesFromTarget(). 

            // Import the robot class
            import { THREERobot } from "./robot.js";
        
            // Initialize the robot with starting positions
            const originPosition = new THREE.Vector3(0, 0, 0);
            const targetPosition = new THREE.Vector3(2, 0, 1);
            const normalVector = new THREE.Vector3(0, 0, 1);  // Normal pointing up
        
            const myRobot = new THREERobot(originPosition, targetPosition, normalVector);
        
            // Add the robot to the Three.js scene
            scene.add(myRobot);
        
            // Set a new target position & normal for the moving leg
            myRobot.target.position.set(3, 1, 2);
            myRobot.target.normal.set(0, 0, 1);  // Keeping same normal
        
            // Update the robot's angles based on the new target
            myRobot.updateAnglesFromTarget();

After running this code, the robot will automatically update its joint angles to reach the new target position.

🔄 Swapping Legs for Movement

While inverse kinematics allows the robot to adjust its position, it must swap its fixed leg to move in space. This is achieved through a leg swap, where the target leg becomes the new fixed leg, and the robot is rebuilt from this new base.

📌 How It Works:

  • ✅ Reconstruct the robot from the new fixed leg (previous target).
  • ✅ Set the new target as the old origin, allowing the cycle to continue.
  • ✅ Recompute inverse kinematics, adjusting joint angles accordingly.

This simple operation enables continuous movement, allowing Bill-E to walk, climb, and reposition dynamically. 

function swapFixedLeg() {
    let temp = this.origin;
    this.origin = this.target;
    this.target = temp;

    this.direction = new THREE.Vector3().subVectors(this.target.position, this.origin.position);
    this.updateAnglesFromTarget(); // Recompute IK for new configuration
}

🎯 Example Usage

Move the robot by setting a target and swapping legs:

robot.target.position.set(2, 0, 1);  // Set new target position
robot.target.normal.set(0, 0, 1);    // Set new target position
robot.updateAnglesFromTarget();      // Compute IK angles
