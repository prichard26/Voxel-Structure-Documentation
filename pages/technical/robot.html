🤖 Bill-E Robot Structure

How the robot is modeled, initialized, and structured in the simulation.

📖 Understanding the Robot Model

The Bill-E robot is modeled using a series of joints and links connected to form a bipedal structure. Each joint has a set angle that defines its movement, while each link represents a rigid segment between joints.


Bill-E is a 5 DOF (Degrees of Freedom) robotic leg system with five joints:

  • Joints 0 & 4: Rotate around the normal axis to the surface.
  • Joints 1, 2, & 3: Rotate around a local perpendicular axis, depending on the robot’s orientation.

Each joint has a rotation range from -135° to 135°, giving a total movement range of 270°. This range ensures the cable-driven actuation remains functional without excessive strain.


Joint angles are defined relative to the previous joint, meaning that each movement is calculated based on the current robot position. The diagram above illustrates how each joint contributes to the robot’s flexibility.

⚙️ Robot Class

The robot is implemented as a class, allowing easy instantiation and modification.

class THREERobot

📥 Inputs:

  • origin: Initial position of the fixed leg.
  • target: Initial position of the moving leg.
  • normal: Orientation of the surface the robot stands on.
  • scene: The Three.js scene where the robot is added.
  • initialGeometry (optional): Default shape and size of the robot’s limbs.
  • limits (optional): Joint constraints to limit rotation.

📤 Output:

  • A fully initialized robot with correct joint angles.
class THREERobot {
    constructor(origin, target, normal, scene, initialGeometry = DEFAULT_GEO, limits = DEFAULT_LIMITS) {
        this.angles = [0, 0, 0, 0, 0]; // Angles of each joint
        this.joints = [];               // Stores each joint object
        this.robotBones = [];           // Three.js objects for rendering
        this.fixed_leg = 0;             // Indicates which leg is fixed (0 or 4)
        
        .
        . 
        .

        this.origin = { 
            position: origin.clone(), 
            normal: normal.clone().normalize() 
        };

        this.target = { 
            position: target.clone(), 
            normal: normal.clone().normalize() 
        };

        this.direction = new THREE.Vector3().subVectors(this.target.position, this.origin.position);

        this.updateAnglesFromTarget();  // Applies inverse kinematics to reach target pos
    }
}

🚀 Key Features

  • 📐 constructor(): Initializes the robot with position and orientation.
  • 🦿 updateAnglesFromTarget(): Applies input angles using inverse kinematics (see IK page).
  • 🔄 swapFixedLeg(): Switches the supporting leg.

🎯 Example Usage

Initialize a new robot in the scene:

import { THREERobot } from "./robot.js";

const leftLegPos = new THREE.Vector3(0, 0, 0);
const rightLegPos = new THREE.Vector3(1, 0, 0);
const normal = new THREE.Vector3(0, 0, 1);
const scene = new THREE.Scene();

const myRobot = new THREERobot(leftLegPos, rightLegPos, normal, scene);
scene.add(myRobot);
