🔲 Voxels in Bill-E Simulation

How voxels are used to build the 3D environment for the robot.

📖 What Are Voxels?

A voxel (short for "volumetric pixel") represents a **small cubic unit** that makes up the 3D environment. Similar to **pixels in 2D images**, voxels define a **grid-based world** where objects can be placed, modified, or removed.

✔ How Voxels Work in Bill-E:

  • 🔲 The world is made up of a **grid of voxels**, defining the terrain.
  • 🧱 Each voxel represents a **solid block** that the robot can walk on.
  • 📏 Voxels have a **fixed size and position**, ensuring precise navigation.
  • 📂 Each voxel is **loaded from an STL file** and placed into the scene.

🚀 Key Features

  • ✅ 3D Voxel Representation: Uses STL models to visualize blocks.
  • ✅ Collision Detection: The global voxelMap tracks existing blocks.
  • ✅ Dynamic Loading: Voxels can be **added** to or **removed** from the scene.

⚙️ The `Voxel` Class

The Voxel class handles the creation and management of individual voxels.

class Voxel

📥 Inputs:

  • x, y, z: The voxel’s position in the world.
  • scene: The Three.js scene where the voxel is added.
  • path (optional): The STL file path for voxel geometry.

📤 Output:

  • A 3D voxel block placed into the scene.
import * as THREE from "three";
import { STLLoader } from "three/examples/jsm/loaders/STLLoader.js";

export class Voxel {
    constructor(x, y, z, scene, path = "../voxel.stl") {
        this.scene = scene;
        this.position = new THREE.Vector3(x, y, z);
        this.loader = new STLLoader();
        if (!window.voxelMap) window.voxelMap = new Set();
        this.loadVoxel();
    }

    loadVoxel() {
        this.loader.load(this.path, 
            (geometry) => this.onVoxelLoaded(geometry), 
            undefined, 
            (error) => console.error("Error loading voxel:", error)
        );
    }

    onVoxelLoaded(geometry) {
        let material = new THREE.MeshStandardMaterial({ color: 0xffffff, metalness: 0.8, roughness: 0.6 });
        let voxelMesh = new THREE.Mesh(geometry, material);

        voxelMesh.scale.set(1, 1, 1);
        voxelMesh.position.copy(this.position);

        this.scene.add(voxelMesh);
        window.voxelMap.add(new THREE.Vector3(this.position.x, this.position.y, this.position.z));
    }
}

🎯 Example Usage

Here’s how to add a voxel into the scene:

import { Voxel } from "./voxel.js";

// ✅ Create a new Three.js scene
const scene = new THREE.Scene();

// ✅ Add a voxel at position (2, 1, 0)
const newVoxel = new Voxel(2, 1, 0, scene);

After running this code, a voxel will be placed in the 3D environment at (2,1,0).
